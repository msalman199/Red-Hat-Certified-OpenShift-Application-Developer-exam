## 🔑 Key Concepts

| Concept | Description |
|---|---|
| **Container** | A lightweight, portable unit that packages an application and its dependencies for consistent execution across environments |
| **Virtual Machine (VM)** | A traditional, heavier-weight isolation model that containers improve on in terms of efficiency and portability |
| **OpenShift Project** | Provides isolation and organization for applications and resources |
| **Pod** | The smallest deployable unit in OpenShift/Kubernetes |
| **Deployment** | Manages an application's lifecycle, including scaling and updates |
| **Route** | Provides external access to applications running inside the cluster |
| **CodeReady Containers (CRC)** | A tool for running a local, single-node OpenShift cluster for learning and development |
