## 🔑 Key Concepts

| Concept | Description |
|---|---|
| **DeploymentConfig** | OpenShift resource used to define and deploy applications |
| **Rolling Deployment** | Zero-downtime update strategy that keeps the application continuously available |
| **Horizontal Pod Autoscaler (HPA)** | Enables automatic scaling based on resource utilization |
| **Manual & Automatic Scaling** | Options for controlling application capacity |
| **Resource Limits** | Constrains resource usage as part of production-deployment best practices |
| **Deployment Hooks** | Runs actions at specific points in the deployment lifecycle |
