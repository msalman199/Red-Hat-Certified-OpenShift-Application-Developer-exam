## 📚 Key Concepts

| Concept | Description |
|---|---|
| **Prometheus** | Metrics collection and time-series database powering OpenShift monitoring |
| **Grafana** | Visualization layer for building dashboards on top of collected metrics |
| **PrometheusRule** | A custom resource defining alerting or recording rules evaluated by Prometheus |
| **AlertManager** | Routes, groups, and dispatches alerts fired by Prometheus rules |
| **Custom Metrics** | Application-specific metrics exposed for monitoring beyond default infrastructure metrics |
| **Mean Time to Detection (MTTD)** | The average time taken to detect an issue after it occurs |
| **Monitoring as Code** | Managing monitoring/alerting configuration declaratively for consistent, repeatable deployments |
