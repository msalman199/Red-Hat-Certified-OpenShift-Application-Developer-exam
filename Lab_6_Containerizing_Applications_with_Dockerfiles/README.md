## 🔑 Key Concepts

| Concept | Description |
|---|---|
| **Dockerfile** | Defines how a container image is built, including security measures and health checks |
| **Multi-Stage Build** | Build technique that produces leaner, more secure container images |
| **Health Check** | Verifies a container's running state as part of the image build |
| **OpenShift Internal Registry** | Stores container images pushed from local builds |
| **Image Stream & Tags** | Manages versioned references to container images in OpenShift |
| **Route** | Exposes a deployed containerized application externally |
| **Automated Deployment** | Advanced image-management technique tying versioning to deployment |
